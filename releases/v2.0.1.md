# Sakoon v2.0.1

A hardening release. The app now behaves in a way that antivirus engines
recognise as normal, and there are two clean ways to install it.

## Why this release exists

Some machines flagged the v2.0.0 executable (`Trojan:Win32/Bearfoos.A!ml`,
a machine-learning heuristic) — a false positive. The most likely trigger
was that Sakoon created its Start-with-Windows shortcut **at runtime**, and
"an unsigned new program writing a Startup entry" is a classic malware
pattern to an ML classifier. v2.0.1 removes that behaviour entirely.

## What changed

- **Sakoon no longer writes to Windows startup itself.** The runtime
  shortcut creation (via `WScript.Shell`) is gone. On upgrade, Sakoon
  removes — once — any startup shortcut an earlier version left behind, so
  you are never stuck with an orphan.
- **Two ways to install, both zipped:**
  - **`Sakoon.zip`** — portable. Unzip and run `Sakoon.exe`.
    Nothing is installed and nothing is added to startup.
  - **`Sakoon-Setup.zip`** — an installer. Unzip and run
    `Sakoon-Setup.exe`. It installs per-user (no admin), adds Start Menu
    and uninstall entries, and creates a `shell:startup` shortcut so Sakoon
    starts with Windows. That option is ticked by default and can be
    unticked during setup.
- **Auto-start is now a Windows / installer decision, not the app's.** If
  you use the portable build and want Sakoon at sign-in, enable it under
  Windows Settings ▸ Apps ▸ Startup, or use the installer.
- **App always opens on the Dashboard.**
- Reproducible-build hygiene: the Wails CLI version is pinned, and release
  builds verify pinned modules instead of re-resolving them.

## What did not change

- All timing, mute/unmute, verification, crash-recovery, snooze, sleep/wake,
  and Jumu'ah behaviour — identical to v2.0.0.
- The native app window, system tray, and the Night / Pearl / Oasis / Amber
  themes.
- Official uploaded tables remain the source of truth; calculated times stay
  labelled **CALCULATED — UNOFFICIAL**.
- Data location `%LOCALAPPDATA%\Sakoon` — settings, tables, and logs carry
  over with no migration.
- No network ports, no account, no ads, no telemetry.

## Included files

- **`Sakoon.zip`** — direct download; contains `Sakoon.exe`. Unzip and run.
- **`Sakoon-Setup.zip`** — installer download; contains `Sakoon-Setup.exe`.
  Unzip and run.
- `Sakoon-Table-Format-Example-NOT-OFFICIAL.csv` — synthetic format example.
- `README-FIRST.txt` — first-run notes and the SmartScreen explanation.
- `SHA256SUMS.txt` — checksums for both zips and the sample.

The filenames carry no version number on purpose, so
`releases/latest/download/Sakoon.zip` and
`…/Sakoon-Setup.zip` stay valid for every future release.

## A note on the Windows warning

v2.0.1 removes the behaviour most likely to trigger a false positive, but it
is still an unsigned, newly-built program, so Windows SmartScreen may still
show *"Windows protected your PC"* on first run. That reflects reputation,
not anything found in the file. Choose **More info**, then **Run anyway**.
Every release publishes SHA-256 hashes if you would rather verify first.

If a detection persists, the fastest fixes are to submit the exact file to
Microsoft as a false positive (free, usually cleared within days) and, in
time, to code-sign releases.

## Install / upgrade

1. Download either `Sakoon.zip` or `Sakoon-Setup.zip`, plus
   `SHA256SUMS.txt`.
2. Verify the SHA-256 hash, then extract.
3. Portable: run `Sakoon.exe`. Installer: run `Sakoon-Setup.exe`.
4. Upgrading from v2.0.0: quit the running Sakoon from the tray first. Your
   settings, tables, and logs carry over automatically.

## Important timing notice

Sakoon is not a religious authority and cannot certify a prayer time. Your
local awqaf publication and mosque override every value. Never rely on
